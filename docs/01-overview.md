# 01. 개요와 목표

> 역할: 프로젝트가 무엇이고 어디까지 하는지를 한 장으로 정리한다. 세부 내용은 다른 문서로 연결된다.

## 한 줄 정의

Claude Code에서 `/extensions-viewer`를 입력하면 보안이 적용된 로컬 URL이 출력되고, 그 페이지에서 스킬·MCP·플러그인 3종 목록을 한눈에 읽는 **읽기 전용** 도구다.

## 왜 만드는가

3종을 확인하는 방법이 제각각이라(`/mcp`, `/plugin`, 폴더 탐색) 한 번에 볼 수 없다.
로컬에서 MVP를 먼저 검증한 뒤 GitHub 오픈소스로 공개하고, 스타 확보를 목표로 한다. 스타 수는 보장할 수 없다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 레포 이름 | `extensions-viewer` |
| 명령 | `/extensions-viewer` (스킬 폴더 `.claude/skills/extensions-viewer/`) |
| 형태 | 읽기 전용 로컬 웹 뷰어 |
| 스택 | Node.js + TypeScript, 런타임 의존성 0 |
| 진행 순서 | 로컬 MVP 테스트 → 공개 준비 → GitHub 공개 |
| 배포 | MVP는 스킬 폴더, 공개 시 npm과 자체 마켓플레이스 검토 |
| 후속 | 웹 ON/OFF 저장(쓰기)은 공개 이후 |

## MVP 범위

대상 환경은 사용자 로컬 PC의 Claude Code(터미널)다.

| 구분 | 항목 |
|---|---|
| 포함 | `/extensions-viewer` 스킬 명령 (사용자 직접 실행만 허용) |
| 포함 | 로컬 서버: 127.0.0.1, 랜덤 포트, 랜덤 토큰 |
| 포함 | 수집기 3종(플러그인, MCP, 스킬) 읽기 전용 |
| 포함 | 단일 화면: 탭 3개 + 검색 |
| 포함 | 민감정보 마스킹, 유휴 자동 종료 |
| 제외 | ON/OFF 및 저장(쓰기), 플러그인 설치·삭제 |
| 제외 | 현재 세션에 실제로 로드된 상태 조회 |
| 제외 | Claude Desktop, claude.ai (이미 Customize 화면이 있음) |
| 제외 | DB, 사용자 계정, 원격 접속 |

## MVP 성공 기준

1. 명령 1회로 URL이 출력된다.
2. 3종 목록이 범위·상태와 함께 표시된다.
3. 토큰이 없거나 Host가 잘못된 요청은 403으로 거부된다.
4. 화면 어디에도 비밀값이 노출되지 않는다.
